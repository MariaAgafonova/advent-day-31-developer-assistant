# На сегодня

Спокойный ежедневник для Android: дела на выбранную дату, голосовой ввод и вечерний разбор. Работает без регистрации и собственного сервера.

**Эта папка — корень Android-проекта и Git-репозитория.** Открывайте её в Android Studio: `app/`, `gradle/`, `gradlew.bat` лежат непосредственно здесь. Старого вложенного проекта glab больше нет.

## Что реализовано

- Добавление и редактирование задач, выполнение и отмена выполнения.
- Выбранный день, переходы назад/вперёд, календарь прошлых и будущих дней, возврат к сегодняшней дате.
- Счётчик выполненных дел, сворачиваемый список выполненных, пустое состояние.
- Перенос существующей задачи на другую дату без копирования. Удаление с отменой через Snackbar.
- Голосовая диктовка через SpeechRecognizer с предпросмотром и подтверждением списка.
- Вечерний разбор конкретной даты: выполнить, перенести на завтра относительно даты разбора, выбрать другую дату, удалить. Каждое решение сохраняется сразу.
- Неточное ежедневное напоминание, по умолчанию выключено; время 22:00. Открытие разбора из уведомления и возврат к списку дел.
- Локальные Room и DataStore, русский интерфейс, светлая и тёмная темы.

## Открытие и сборка

Нужны Android Studio с поддержкой AGP 9.2.1, JDK 17+ (для компиляции Kotlin используется JDK 17), Android SDK Platform 36 и Build Tools 36.0.0. Минимальная версия устройства — Android 8.0 / API 26; target/compile SDK — 36. Gradle Wrapper включён.

Укажите путь SDK в `local.properties` (Android Studio создаёт файл автоматически). Для текущей машины:

```properties
sdk.dir=D:/AndroidSDK
```

Команды PowerShell из этой папки:

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug
.\gradlew.bat :app:connectedDebugAndroidTest
```

APK: **`app/build/outputs/apk/debug/app-debug.apk`**.

Последняя команда требует подключённого устройства или эмулятора и запускает тесты с очисткой данных тестируемого приложения. Используйте отдельный тестовый эмулятор. На текущей машине используется Pixel_10 / Android 16.

Если глобальная конфигурация Gradle ограничивает Metaspace, проверенная команда:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:connectedDebugAndroidTest --console=plain "-Dorg.gradle.jvmargs=-Xmx3g -XX:MaxMetaspaceSize=1536m -Dfile.encoding=UTF-8"
```

## Как пользоваться

Выберите день нажатием на дату. Кнопки со стрелками открывают соседние дни, «Сегодня» возвращает к текущей календарной дате. Добавьте дело кнопкой «Добавить задачу». Нажмите на название, чтобы изменить его; меню задачи содержит перенос и удаление. После удаления доступна кнопка «Отменить» в Snackbar.

Экран «Подвести итоги дня» показывает незавершённые дела выбранной даты. Кнопка «На завтра» содержит итоговую дату переноса. Задачи не переносятся автоматически. Счётчик выполненных — текущее количество выполненных задач, запланированных на этот день. Счётчик переносов относится к текущему сеансу разбора и начинается заново при новом открытии.

История показывает текущее состояние записей, а не полный журнал переносов. Перенесённая задача исчезает из исходного дня и не считается выполненной.

## Голосовой ввод

Откройте «Голосом» → «Начать диктовку», разрешите доступ к микрофону. Произносите **«новая задача»** между делами:

> Купить продукты новая задача закончить отчёт новая задача позвонить маме

Союзы и запятые не разделяют задачи. До подтверждения можно исправить распознанный текст, заново разделить его, изменить отдельные задачи, добавить/удалить строку, объединить со следующей или разделить вручную переносом строки. Повторное разделение исходного текста заменяет правки списка. Пустые задачи нельзя сохранить.

Распознавание зависит от сервиса устройства. Оно может требовать сети и передавать аудио провайдеру распознавания. Приложение не сохраняет аудиозаписи и не гарантирует офлайн-распознавание. При отказе в доступе, отсутствии сервиса или ошибке можно воспользоваться текстовым вводом.

## Как проверить уведомления

1. В «Настройках» включите вечернее напоминание и разрешите POST_NOTIFICATIONS на Android 13+.
2. Установите ближайшее будущее время. Убедитесь, что уведомления и канал «Вечерний разбор» разрешены в Android.
3. Дождитесь уведомления «Как прошёл день? / Отметь выполненные дела». Оно приходит **примерно**, не точно в минуту.
4. Нажатие открывает разбор даты, для которой был назначен alarm; «Назад» возвращает к планировщику.
5. Измените время: остаётся одно запланированное событие. Выключите переключатель: alarm и видимое уведомление отменяются.

Механизм — одноразовый `AlarmManager.setAndAllowWhileIdle(RTC_WAKEUP)`, после доставки рассчитывается следующий местный день. Exact alarms и исключение из энергосбережения не запрашиваются. Перепланирование предусмотрено при перезагрузке, смене времени/даты/зоны и обновлении пакета; открытие приложения также восстанавливает расписание.

Задержки возможны из-за Doze, экономии энергии и правил производителя. После принудительной остановки нужно снова открыть приложение. Если уведомление задержалось за полночь, оно сохраняет исходную дату разбора.

## Технические решения

Kotlin, Compose Material 3, ViewModel + StateFlow + Coroutines, Room 2.8.4, Preferences DataStore 1.2.1, Navigation Compose 2.9.6. Без DI-фреймворка, дополнительных модулей и собственного сервера. Настройки и задачи сохраняются после перезапуска.

`scheduledDate` — LocalDate/epochDay без часового пояса. `createdAt` и `completedAt` — Instant/UTC epoch millis. Смена зоны не сдвигает дату задачи. Переходы через месяц, год и високосный день выполняются средствами java.time. Локальное время напоминания пересчитывается в текущей зоне; DST-gap сдвигается вперёд, при неоднозначном времени используется первое вхождение.

Полного журнала действий, аккаунтов, синхронизации, экспорта и облачного резервного копирования в MVP нет. Настройки резервного копирования исключают локальные данные.

## Ассистент разработчика

Python-ассистент остаётся отдельным терминальным инструментом и изучает документацию этого же Android-репозитория. Он не входит в APK. Инструкции установки, индексации, `/help` и проверки MCP — [docs/assistant.md](docs/assistant.md).

Для самого Android-приложения ключи API не нужны. Для генерации ответа Python-ассистентом используются `OPENAI_API_KEY` и `OPENAI_MODEL`; без них доступны индексация, поиск и MCP.

## GitLab

В Git включаются исходники, документация, Gradle Wrapper, схема Room и файлы зависимостей Python. `local.properties`, ключи, виртуальное окружение, индекс, модель, IDE-файлы и результаты сборки исключены через `.gitignore`.

Создайте пустой репозиторий в своём namespace GitLab, затем укажите его адрес:

```powershell
git remote add origin https://gitlab.com/YOUR_NAMESPACE/na-today.git
git push -u origin main
```

Адрес удалённого репозитория автоматически не задаётся. Результаты проверок и оставшиеся ограничения — в [docs/verification.md](docs/verification.md).
