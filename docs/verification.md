# Проверка MVP

Дата: 15 октября 2026. Windows, JDK 21 для запуска Gradle / toolchain JDK 17, Android SDK 36, эмулятор Pixel_10 (API 36). Проверки выполнялись реальными командами; ответы API и распознавание живой речи не подменялись заготовками.

## Автоматические проверки Android

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:connectedDebugAndroidTest --console=plain "-Dorg.gradle.jvmargs=-Xmx3g -XX:MaxMetaspaceSize=1536m -Dfile.encoding=UTF-8"
```

- 9 unit-тестов: разделение диктовки, кириллический регистр, сохранение союзов/запятых; редактирование/объединение/разделение предпросмотра; счётчик разбора; конец месяца/года, високосный день; время, зона, DST; конвертеры дат и временных отметок; сообщения ошибок распознавания.
- 10 instrumented-тестов на API 36: 5 настоящей Room/repository, 1 расписания и 4 интерфейса.
- Room: создание, обрезка пробелов, выполнение/отмена, идемпотентность, перенос той же записи без дубликатов, переименование, удаление/двойная попытка восстановления, атомарный отказ от пустого элемента в партии, повторное открытие базы.
- UI: пустое название, создание/изменение, выполнение/отмена, удаление/отмена, recreation Activity, перенос через вечерний разбор, предпросмотр голосового списка, реальное уведомление и его PendingIntent, дата разбора и Back.
- Напоминания: включение, изменение времени, единственный актуальный token, отклонение старого события, повторное ensureScheduled, выключение и отмена видимого уведомления.
- Lint: **0 ошибок, 16 предупреждений** — более новые версии SDK/библиотек и оставшийся qualifier v26 у ресурса иконки. Проверки не подавлены baseline-файлом.
- Debug APK успешно собирается: `app/build/outputs/apk/debug/app-debug.apk`.

Исправлены найденные ошибки: регистронезависимость кириллицы в разделителе; чтение ресурсов Snackbar с учётом конфигурации; оформление действий при крупном шрифте. В тестовой инфраструктуре закреплён Espresso 3.7.0 вместо транзитивного 3.5.0, несовместимого с API 36. Тест уведомления восстанавливает исходный Intent только после проверок, чтобы ActivityScenario корректно завершил Activity: AndroidX сопоставляет lifecycle-события по исходному Intent.

## Ручные проверки эмулятора

- Разрешение RECORD_AUDIO отклонено в системном диалоге: показаны понятное сообщение и переход к настройкам, текстовый ввод доступен.
- Задача PersistenceCheck создана через UI, приложение force-stop и заново запущено: задача сохранилась.
- Зона изменена с Europe/Budapest на Asia/Tokyo: «Сегодня» перешло с 15 на 16 октября. Задача осталась в исходном 15 октября, доступна в истории. Зона и автоматическое определение восстановлены.
- Календарь открыл 31 октября 2026; следующий день — 1 ноября. Возврат «Сегодня» работает.
- Светлая и тёмная темы осмотрены на скриншотах. При font scale 1.8 обнаружен неудачный перенос кнопки добавления; для крупного шрифта действия перестроены в столбец.
- Исправленный экран повторно осмотрен при font scale 2.0: обе кнопки полностью читаемы и доступны, содержимое списка прокручивается. Исходные шрифт 1.0 и светлая тема восстановлены.
- В настройках вручную выдано POST_NOTIFICATIONS, включено напоминание и изменено время с 22:00 на 23:05. dumpsys alarm подтвердил одно одноразовое RTC_WAKEUP событие на новое время.
- Эмулятор перезагружен и разблокирован: без открытия приложения boot-receiver восстановил alarm на 23:05; проверено в dumpsys alarm.
- Реальный alarm доставил уведомление примерно в 23:06 после перезагрузки. Нажатие из системной шторки при закрытом приложении открыло разбор 15 октября 2026; системная кнопка Back вернула на главный экран. Это отдельная ручная проверка доставки по часам, без прямого вызова обработчика.
- После проверки напоминание выключено, время возвращено к 22:00; активного alarm приложения в системном расписании нет.
- Кнопки имеют Material touch targets и описания для accessibility. Полный пользовательский прогон с TalkBack не проводился.

## RAG/MCP

После подключения DeepSeek: **36 passed**, включая три настоящих API-запроса. Проверены ответ на русском о структуре с источниками документации и MCP:list_project_files, текущая ветка с MCP:get_current_branch и отказ отвечать про неподтверждённую функцию. Модель настроена как `deepseek-v4-flash`, таймаут 90 секунд, max_tokens 1024. Реальная генерация OpenAI отдельно не проверена: его ключ и модель не заданы.

Первый живой тест выявил отсутствие ссылки на MCP_FILES в ответе о структуре. Уточнена инструкция и добавлена обязательная проверка обеих групп источников перед показом ответа; повторный полный прогон прошёл. Новые локальные тесты проверяют выбор провайдера, параметры, границу инструкций/данных, JSON, неполный ответ, неизвестные ссылки и безопасные сообщения об ошибках API. Ключ находится только в игнорируемом `.env`; пример конфигурации не содержит секрета. Предупреждения Python — DeprecationWarning конфигурации embeddings в Chroma.

Проверены индекс README/docs с корректными строками, переиндексация без дубликатов, удаление документов, русский поиск по английской документации, MCP stdio как отдельный процесс, ветка Git, настоящие отслеживаемые пути, ошибки MCP, контекст вопроса о структуре. Новый индекс заменяет содержимое старого корпуса glab.

## Ограничения проверки и MVP

- Успешная диктовка реальным голосом через микрофон физического устройства не проверена. Реализованы SpeechRecognizer и жизненный цикл, проверены парсер/редактор и отказ в разрешении; качество, поддержка русского и офлайн-режим зависят от провайдера устройства.
- Доставка неточного alarm в Doze и на устройствах разных производителей не проверена. Интеграционный тест вызывает обработку назначенного события и затем открывает настоящее уведомление; доставка по часам дополнительно проверена вручную на эмуляторе после перезагрузки.
- На устройствах Android 8–15 и Android 17 проверки не запускались; фактический эмулятор — Android 16.
- Нет синхронизации, аккаунтов, экспорта, журнала переносов и облачного backup. Удаление приложения удаляет локальные данные.
- GitLab remote не задан; сетевой push не выполнялся.
